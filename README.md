# ai-flip.ru

Сайт [ai-flip.ru](https://ai-flip.ru) — доступ к нейросетям ChatGPT, Claude, Gemini, DeepSeek и другим в одном окне.

Сайт работает на платформе [OnPress](https://onpress.pro) v2: страницы, шаблоны и контент живут в OnPress и собираются по шаблону на стороне платформы. В этом репозитории — публичная история изменений сайта.

## Чейнджлог

Релизы этого репозитория (вкладка Releases) могут публиковаться на сайте записями чейнджлога через интеграцию OnPress «GitHub → чейнджлог». Подробнее — в [документации OnPress](https://onpress.pro/docs/v2/ru/api/automation/).
